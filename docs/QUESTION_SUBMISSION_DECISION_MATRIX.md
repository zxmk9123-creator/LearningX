# 학생 질문 전송 판정표

작성·수정은 문안별로 판정한다. 교수자 공개는 현재 문안의 적합 판정, 참여 권한, 질문을 받는 수업 상태가 모두 충족될 때 허용한다.

| 문안 및 상태 | 학생 화면 | 단건·일괄 요청 |
| --- | --- | --- |
| 정상 질문, 인용 분석, 학술적 반론, 구체적 수업 개선 요청 | 검사 통과 후 선택 가능 | 현재 문안이면 발송 |
| 개인정보 또는 사생활 요청, 인신공격, 수업 조롱, 광고·반복, 반응만 있는 입력 | 수정 안내, 선택 불가 | 거부 |
| 수업 무관 또는 가리키는 개념·교안 선택이 없는 지시어 질문 | 안내 문구만 표시, 전송 목록 제외 | 거부 |
| 교수자나 타인에게 호감을 고백하거나 교제를 요청하는 말 | 안내 문구만 표시, 전송 목록 제외 | 거부 |
| 실재 수강생이나 같은 반·조의 특정 학생 언급 | 안내 문구만 표시, 전송 목록 제외 | 거부 |
| 단순 사실·용어 정의·정답·외부 검색 요청 | 안내 문구만 표시, 전송 목록 제외 | 거부 |
| 여러 차단 사유가 겹치는 문안 | 사유를 모두 반환하고 우선순위가 높은 안내를 표시 | 차단 사유 하나로도 거부 |
| 검사 중, 모델 실패, 검사 기록 없는 이전 초안 | 선택 불가, 검사 완료 또는 재검사 필요 | 거부 |
| 수정 후 이전 문안 번호로 요청 | 최신 문안 재확인 필요 | 거부 |
| 일괄 목록에 적합 문안과 차단 문안이 섞임 | 해당 문안을 선택할 수 없음 | 요청 전체를 거부, 교수자 보드 변화 없음 |
| 권한 없음, 다른 참여자의 질문, 수업 중지·종료 | 접근 또는 전송 제한 | 거부 |
| 이미 완료된 전송을 같은 식별자로 재시도 | 기존 전송 결과 사용 | 추가 공개 없이 이전 성공 재사용 |

게스트 수업의 관련성 판단은 명시적 규칙 범위에 한정된다. 모델을 쓰는 수업은 문맥 판정을 추가한다. 반복은 작성 시점의 같은 참여자·수업 내 기록을 기준으로 판단한다. 검사 이후 다른 질문이 작성됐다는 이유로 이전 판정을 소급 변경하지 않는다.

이전 미전송 초안은 현재의 문안 자체만으로 판단 가능한 규칙을 다시 적용한다. 이미 발송된 질문은 발송 기록을 보존한다. 기존 단건 API도 적합 판정을 요구하며 이전 강제 적용 플래그로 전송을 열 수 없다.

차단된 질문에는 “반응만 적기보다 수업에서 궁금하거나 더 알아보고 싶은 내용을 적어 주세요.”만 표시하며, 수준과 코칭을 공개하지 않는다. 검사 대기 중에도 전송 목록에는 들어가지 않는다. 수업 일정·과제 제출처럼 수업 운영에 필요한 확인, 특정인을 지목하지 않는 학습 사례, 개념을 비교하거나 적용하는 질문은 허용한다.

반말 고백, 숫자·초성·기호로 변형한 욕설, 단순 정보 조회나 개인적 요청이 학습 질문과 섞이면 해당 사유를 함께 판정한다. 인용 예외는 표현을 실제로 분석하는 구절에만 적용한다.
