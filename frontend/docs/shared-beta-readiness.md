# LearningX 운영진 공유 베타 — 연결 게이트 (미확정)

> **2026-11-17 확인 결과:** 사용자 메시지의 `{{SHARED_API_BASE_URL}}`,
> `{{API_DOC_LOCATION}}`, `{{BETA_INVITE_SECRET_NAME}}`,
> `{{RETENTION_POLICY}}`, `{{COACHING_TIMEOUT_SEC}}`는
> 실제 설정값이 아니다. GitHub `LearningX` 코드 검색, 연결된 프로젝트 목록,
> Vercel 구성, Google Drive 문서 검색에서도 운영진 공유 API 정보가 확인되지 않았다.
> 현재 프론트엔드에는 **어떤 공유 서버에도 요청하지 않는 안전한 홈 UI**만 추가했다.
> 기존 FreeLLMAPI와 Neon 프로젝트가 이 운영진 서버라고 추정하지 않는다.

## 1단계: 문서/실제 HTTP 응답 대조

아래 항목은 모두 **미확인**이다. 지원하지 않는 기능을 클라이언트에서 모의로 만든 후
실제 베타라고 표시해서는 안 된다.

| 기능 | 공유 서버 엔드포인트 | 실제 지원 | 확인해야 할 응답/제약 |
|---|---|---|---|
| 상태 확인 | 미확인 | 미확인 | 접근 가능 여부, 인증 여부, 실패 상태 |
| 베타 초대 검증→교수자 세션 | 미확인 | 미확인 | 쿠키 HttpOnly/SameSite, 메모리 토큰 대안 |
| 업로드 시작 | 미확인 | 미확인 | 서명 URL, 형식, 최대 크기, 속도 제한 |
| 업로드 완료 | 미확인 | 미확인 | 서버 측 재계산 SHA-256, 크기 검증 |
| 분석 작업 조회 | 미확인 | 미확인 | 원본 상태값, 재시도/취소, 만료 |
| 승인 후보 | 미확인 | 미확인 | 역할/품질/미디어/Vision/차시 후보 |
| 블록 승인 | 미확인 | 미확인 | 교수자 서명 및 승인 무결성 |
| 수업 코드 | 미확인 | 미확인 | 발급·입장·만료 및 제한 |
| 학생 질문 코칭 | 미확인 | 미확인 | 실응답 JSON, timeout 계약, 근거 필터 |
| 질문 수정 | 미확인 | 미확인 | 원 질문과 수정 질문의 연결 |
| 교수자 질문 목록 | 미확인 | 미확인 | 폴링/SSE, 익명화 |
| 교안·수업 삭제 | 미확인 | 미확인 | 삭제 완료·예외·권한·보관 기간 |
| CORS | 미확인 | 미확인 | Vercel 정식·Preview Origin, credential 방식 |

**서버 문서와 라이브 응답이 다르면 실제 응답을 우선**으로 기록한다.
인증·데이터 보안 규약에 충돌이 있으면 구현을 중단한다.

## 실서버 연결을 막는 항목

- 운영진 제공 **실제 HTTPS 공유 API 주소**와 **접근 가능한 OpenAPI 문서**
- 운영진의 **GitHub Actions Secret 이름** (값은 읽거나 기록하지 않음)
- 자료 보관 기간 및 삭제 방법, 업로드 동의 문구의 운영진 확정본
- 코칭 시간 제한과 실패·재시도 기준 (과거 NIT 엔진 25초는 이 서버의 SLA가 아님)
- 학생용 서버 응답에서 **미승인 학습 블록, 제공 답안, 교수자 노트, 미검증 도표,
  분석하지 않은 오디오 정보가 응답 본문·토큰·브라우저 저장소에 포함되지 않는지**
- Vercel 출처에서 CORS, 쿠키 보안, 비공개 저장소 직접 업로드 허용 여부

**학생용 자료 projection 검증 실패 시** 홈 화면/실습실 실제 기능을 열지 않는다.
데모 `data/demo-nit.json` 전체가 브라우저로 내려오는 것은 가상 교안에만 허용된다.

## 이미 작성한 배포 준비

| 파일 | 역할 |
|---|---|
| `frontend/index.html` | 홈 첫 화면의 교수자·학생 진입 UI 및 실제 베타/데모 구분 |
| `assets/beta-home.css` | 기존 `#1B64DA` 토큰, 1440px/390px 반응형 |
| `assets/beta-config.js` | 공용 설정값을 **빈 값**으로 유지, 비밀값 불포함 |
| `assets/beta-home.js` | 코드 정규화 및 미설정 시 모든 실제 업로드·인증 차단 |
| `assets/pilot-dev.js` | 실습실 URL/JWT 입력은 `?dev=1`에서만 표시 |
| `tests/beta_gate_e2e.py` | Playwright: 무단 업로드 금지·명시적 데모·모바일 레이아웃 |
| `tests/beta_contract_gate.mjs` | 정적 비밀값·임의 요청·안전 가드 검사 |

**현재 단계의 UI를 실제 베타로 시연하면 안 된다.**
서버 연동과 실제 응답 테스트가 확보되기 전에는 교수자·학생 조작이
온라인 분석·코칭을 수행하지 않는다.

## 서버 연결 구현 결정 시점

1. 운영진 OpenAPI 문서 열람 및 `/docs`/JSON 형태 확인(주소를 추측하지 않는다).
2. 읽기 전용 서버 상태 점검 및 실제 응답 키·에러 구조·CORS/쿠키 동작 비교.
3. `frontend/assets/beta-config.js`의 **공개 설정값만** 채움. 초대 코드 값,
   JWT, S3 서명 자격증명은 프론트 코드에 넣지 않는다.
4. 실서버/브라우저 API 어댑터를 문서에 맞게 신규 구현하고
   서버 응답에만 기반한 상태 전이·승인 제한/진행률/재시도/익명 질문을 연결.
5. 모의 서버 테스트는 **2단계에서 확인한 실제 응답 형식 그대로** 작성.
6. 별도 `workflow_dispatch`로 Actions Secret을 주입받아 **가상 PDF 1건**
   업로드·분석·승인·학생 질문을 실행하고 각 단계 지연을 측정. 현재 워크플로는
   실제 API도 Secret 이름도 없으므로 만들지 않는다.

## 서버 미지원 기능이 드러나면

- CORS 미지원: 운영진 서버에서 Vercel origin 허용(설정만, 가장 간단) **또는**
  별도 서버 사이드 프록시(구축·운영 비용/쿠키·보안 검증 추가)를 비교하고 결정받는다.
- 수업 코드/익명 질문/삭제 부재: 프론트에서 가짜 성공을 내지 않고
  운영진 서버 변경 요청으로 분류한다.
- 대용량 직접 업로드 부재: 32.9MB PPTX가 Vercel Functions 본문 제한을
  우회할 수 있는지 운영진 확인 전에는 진행하지 않는다.
- 학생 자료 노출: proxy로 텍스트를 숨기는 식의 임시 우회를 하지 않으며
  **서버 측 승인 블록 전용 serializer**가 마련될 때까지 연동 중단.
